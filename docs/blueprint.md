# **App Name**: TechRevive

## Core Features:

- Smart Troubleshooting Tool: An AI-powered diagnostic tool that uses reasoning to provide users with potential fixes for common PC and software issues before booking a service.
- Service Booking & Lead Capture: A contact form allowing users to submit service requests, with data stored directly in Firestore for real-time lead management.
- Pricing & Services Dashboard: A structured service directory displaying software and hardware solutions with card-based UI and clear pricing tiers (₹50-₹400).
- One-Touch Communication: Persistent floating buttons and CTAs that connect users instantly to WhatsApp (+919593088017) or direct phone calls.
- Business Portfolio: An 'About' section highlighting Usnish Banerjee's technical experience and the service coverage in Ashoknagar & surrounding areas.
- Live Location Embed: Integrated interactive map highlighting the service base near Sherpur Kalibari, Ashoknagar.

## Style Guidelines:

- Primary color: Electric Professional Blue (#245DC1), a vibrant yet trusted hue conveying technical authority.
- Background color: Arctic White (#F9FAFB), heavily desaturated to keep the interface clinical, clean, and modern.
- Accent color: Cyan Spark (#17B1E0), an analogous hue used for interactive elements like buttons and service icons to create contrast.
- Headlines use 'Space Grotesk' (sans-serif) for a futuristic, computerized feel; body text uses 'Inter' (sans-serif) for maximum readability on small screens.
- Linear, minimalist icons with subtle tech/circuit patterns used to categorize software and hardware services.
- Mobile-first card layout with soft shadows and generous padding to ensure professional density and clarity on desktop.
- Subtle entrance transitions for cards and a sticky navigation bar with a smooth backdrop-blur effect on scroll.
